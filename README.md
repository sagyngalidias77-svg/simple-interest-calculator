# Simple Interest Calculator

This Bash script calculates simple interest on a principal over a specified number of years.

Run `bash simple-interest.sh` and enter the principal, annual interest rate as a percentage, and time in years.

**Formula**: interest = principal × annual rate × years ÷ 100.

For a principal of 1000 at 5% per year for 2 years, the interest is 100.00.
